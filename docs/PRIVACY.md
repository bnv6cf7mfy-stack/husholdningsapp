# Privacy

## Privacy by design

The app collects only data required to support household workflows.

## Adult personal data

- display name
- email identity in auth provider
- household membership data

## Child-related data

- name
- date of birth
- profile image URL (future private storage)
- measurements
- quotes
- notes
- milestones
- calendar links

## Processing principles

- minimization
- purpose limitation
- household isolation
- secure-by-default access controls

## Access control

RLS ensures users only access households they belong to.

## Public exposure policy

No public profile pages or indexing of household/child data.

## Future user rights

Architecture is prepared for export and deletion workflows per household.
