# Child Data Privacy

## Data classes

Sensitive child-related data includes:

- name and date of birth
- profile image URL
- measurements
- quotes
- notes
- milestones
- child-calendar links

## Privacy controls

- RLS enforced by household membership
- no public child pages
- no search indexing
- private storage only for child media
- data minimization and purpose limitation

## Logging rules

- audit metadata yes
- avoid unnecessary replication of sensitive free text in audit payloads

## Future data rights

Architecture prepared for export/delete flows per household and child.
