# Contributing

## Branching

- Base branch: `main`
- Feature branches: `feature/<domain>`

## Commit style

Use Conventional Commits.

Examples:

- `feat(children): add child profile and measurements`
- `feat(calendar): allow creating child quotes from day view`

## Definition of done

A feature is done when:

- functionality works
- lint passes
- typecheck passes
- tests pass
- RLS reviewed/tested
- loading/empty/error states handled
- mobile UX checked
- docs updated
- `PROJECT_STATUS.md` updated
- `TASKS.md` updated
